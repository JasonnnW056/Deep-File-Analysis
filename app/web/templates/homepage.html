Two ways to check a file

Not sure which to pick? Choose hybrid. Use fast when you only need a quick look.

Fast scan

Takes a few seconds

Think of reading the label on a parcel and x-raying it without opening it. We look at the file but never run it.

What we look at

  • Whether the file is really what its name says. A “photo.jpg” can secretly be a program.
  • Whether it matches patterns found in known harmful files.
  • Web addresses and other hidden text inside it.
  • Signs it has been scrambled to hide what’s inside.

What it can’t tell you

What the file does once it’s opened. A clever file can look harmless until it runs.

Good for

Quick checks, documents and images, or when you have many files to get through.

Hybrid scan

Takes 2 to 10 minutes

Everything in a fast scan, plus a test run. We open the file inside a sealed virtual computer and watch what it does. It’s like trying a suspicious gadget in a lab instead of at your desk.

What we watch for

  • Changes to the computer’s settings.
  • Attempts to hide itself or delete its own traces.
  • Collecting information about the computer.
  • New files it creates or drops.
  • Connections to websites or other computers.

Good for

Unknown programs, installers, and anything you were sent and don’t fully trust.

Keep in mind

Some harmful files wait or check whether they’re being watched, so a quiet test run is not a guarantee.

What happens in a hybrid scan

  1. You uploadThe file goes to our server. It is never opened on your computer.
  2. Read-only checkThe fast scan runs first, so you get early results.
  3. Test runA fresh virtual computer opens the file for about a minute and records what happens. It’s reset afterwards.
  4. ReportBoth results are combined into one risk level, with a list of what we found.

Reading your results

No findings
Nothing stood out. This does not prove the file is safe.
Low
Minor oddities that are common in ordinary software.
Medium
Several signs worth checking before you open the file.
High
Strong signs of harmful behavior. Don’t open it.

In a hybrid scan, the final risk is the higher of the two results. A quiet test run can’t hide something the fast scan found, and the other way round.

What happens to your file

While it’s scanned, your file sits in a private temporary folder on the server and is deleted when the scan ends. In a hybrid scan, a copy also goes to the sandbox, which keeps its own record of the test run.

The report details (file name, fingerprints and findings) are saved in History so you can reopen them. Please don’t upload files that contain private information.

Words you might see in a report
Sandbox
A sealed virtual computer used for test runs. Whatever the file does stays inside it.
Signature or rule
A pattern that identifies a known kind of harmful file, like a fingerprint match.
Packed
Scrambled or compressed so the contents are hard to read. Common in both harmful and ordinary software.
Hash
A short code that identifies a file exactly. Two files with the same hash are identical.
MITRE ATT&CK
A public list of known attacker techniques. Reports use its codes, such as T1082, to name what a file did.
